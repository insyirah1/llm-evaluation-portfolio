# AI / LLM Evaluation Portfolio

An independent portfolio demonstrating structured AI/LLM response evaluation, quality review, factual checking, and evidence-based reasoning.

## Portfolio Overview

This portfolio contains independent practice samples created to demonstrate AI response evaluation skills. The examples focus on identifying factual errors, instruction violations, incomplete content, prohibited information, and data-quality issues.

## Evaluation Criteria

Each response is reviewed using the following criteria:

- Accuracy
- Relevance
- Instruction Following
- Clarity
- Completeness
- Overall Judgment

## Case Studies

The portfolio includes examples involving:

1. Instruction violation and unsupported verification methods
2. Factual accuracy versus instruction following
3. Exact sentence-count and prohibited-content violations
4. Data-cleaning advice that conflicts with user constraints

## Evaluation Approach

My evaluation process includes:

1. Reading the prompt carefully
2. Identifying explicit constraints
3. Checking factual claims and calculations
4. Assessing each evaluation criterion independently
5. Writing concise, evidence-based reasoning
6. Forming an overall judgment based on the severity and scope of issues
